# Image Toolkit Web

高度な画像処理、定量分析、3D可視化のための、Next.jsとWebGLで構築されたモダンなWebアプリケーションです。

![App Logo](public/logo.png)

[English](./README.md) | [中文](./README_zh.md)

## 🎯 機能特徴

### 📸 画像処理と分析

- **フォーマット対応**: PNG, JPG, JPEG, RAW形式のドラッグ＆ドロップアップロードに対応。
- **グレースケール変換**: 線形正規化と自動キャリブレーションのための高精度アルゴリズム。
- **領域分析**: 対象領域の詳細分析のためのインタラクティブな矩形選択ツール。
- **定量データ**: リアルタイムのヒストグラム生成、ピクセル分布統計、プロファイリング。
- **データエクスポート**: 外部処理のために分析結果をCSVまたはExcel形式でエクスポート可能。

### 🎨 ピクセルアートとディザ効果

- **リアルタイムディザリング**: 順序ディザリング効果（Bayer, Halftone, Noise, Crosshatch）を適用。
- **カラーモード**: グレースケール、デュオトーン、カスタムパレットに対応。
- **アニメーション**: ダイナミックなグリッドサイズの呼吸効果とアニメーションノイズパターン。

### 🔄 点群と3D可視化

- **データインポート**: CSV/Excel点群データ（X, Y, Grayscale）から画像を再構成。
- **3Dレンダリング**: Three.jsとReact Three Fiberを使用したインタラクティブな3D表面可視化。
- **ビュー制御**: 高さスケーリング、カラーマッピング、パルスアニメーション、自動回転をサポート。
- **エクスポート**: 再構成された2D画像または3Dビューのスナップショットをダウンロード。

## 🚀 はじめに

### 必須要件

- Node.js 18+
- npm または yarn

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/yourusername/image-toolkit-web.git

# プロジェクトディレクトリに移動
cd image-toolkit-web

# 依存関係をインストール
npm install
```

### 開発モード

```bash
# 開発サーバーを起動
npm run dev
```

[http://localhost:3000](http://localhost:3000) にアクセスしてアプリケーションを表示します。

### 本番ビルド

```bash
# 本番用にビルド
npm run build

# 本番サーバーを起動
npm start
```

## 🛠️ 技術スタック

- **フレームワーク**: Next.js 15 (App Router)
- **言語**: TypeScript
- **スタイル**: TailwindCSS v4
- **UIコンポーネント**: shadcn/ui
- **アイコン**: Lucide React
- **可視化**:
  - Recharts (2Dチャート)
  - Three.js + React Three Fiber (3Dレンダリング)
  - Aceternity UI (ディザシェーダー)
- **アニメーション**: Framer Motion
- **データ処理**: SheetJS (xlsx)

## 📊 データ形式

### 点群インポート/エクスポート (CSV)

アプリケーションは以下の構造を持つCSVファイルを想定しています：

```csv
X,Y,Grayscale
0,0,128
1,0,255
0,1,64
```

- **X**: 水平座標（ピクセル列）
- **Y**: 垂直座標（ピクセル行、下から上への数学座標系）
- **Grayscale**: 輝度値 (0-255)

## 📝 使用フロー

### 画像 → 点群

1. **アップロード**: 画像ファイルを選択します。
2. **分析**: キャンバス上でマウスを使って領域を描画します。
3. **統計確認**: 選択した領域のヒストグラムと統計指標を確認します。
4. **エクスポート**: ピクセルデータを標準化されたCSV点群ファイルとして保存します。

### 3D 可視化

1. **インポート**: 有効なCSV点群ファイルをアップロードします。
2. **レンダリング**: システムが自動的に2D画像を再構成し、3D地形マップを生成します。
3. **操作**: 3Dビューを回転、ズーム、パンします。グリッドの切り替えやレンダリングモードの変更が可能です。
